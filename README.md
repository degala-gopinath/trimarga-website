# TRIMARGA — Business Growth Partners (React + Tailwind CSS)

Hand-crafted editorial agency website built in React, Vite, and Tailwind CSS following the **Trimarga Website Content — Developer Handover** specification.

## Key Architectural Details
- **Editorial Agency Design**: Sharp architectural grid lines (`1px` dividers), `Playfair Display` serif headlines paired with `Plus Jakarta Sans` UI typography, and strict adherence to Black (`#0A0A0A`), White (`#FFFFFF`), and Trimarga Yellow (`#FBAF01`).
- **Complete 16-Route Sitemap**:
  - `/` (Home)
  - `/services` (Services Overview & 3 Packages)
  - `/services/website-design`
  - `/services/ecommerce-websites`
  - `/services/portfolio-websites`
  - `/services/google-business-profile`
  - `/services/digital-presence-setup`
  - `/services/social-media`
  - `/services/branding`
  - `/services/meta-ads`
  - `/services/google-ads`
  - `/services/seo`
  - `/services/geo`
  - `/about`
  - `/work`
  - `/contact`
- **Centralized Global Config**: Update domain, email, phone, and social handles in one file (`src/data/siteConfig.js`).

## Local Development

```bash
npm install
npm run dev
```
